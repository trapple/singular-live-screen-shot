## ストアの掲載情報

### 名前 (最大 45 文字)

```
Singular Live Screenshot
```

### 概要 / 短い説明 (最大 132 文字)

```
SINGULAR LIVE のアーカイブ動画から、再生 UI を写し込まずに 1920x1080 の静止画を保存します。1 コマ単位の送り戻しにも対応。
```

### 詳細な説明

```
SINGULAR LIVE (singular-live.thinkr.jp) のアーカイブ動画を見ているときに、気に入った
場面を静止画として手元に保存するための拡張機能です。

■ できること

・ホットキー (既定: Shift+S) を押すと、その瞬間の映像を PNG で保存します
・一時停止中に 1 コマ単位で送り戻しできます (→ / ←)
・一時停止中に 1 秒単位で送り戻しできます (Shift+→ / Shift+←)
・一時停止すると、操作用のボタンが画面に表示されます
・全画面表示中もすべての機能が使えます

■ 画面の操作ボタンが写り込みません

映像データそのものから静止画を取り出しているため、画面に重なっている再生コント
ロールやオーバーレイは保存される画像に含まれません。また、ウィンドウに表示されて
いる大きさではなく、配信そのものの解像度 (1920x1080) で保存されます。

■ 1 コマ単位で位置を合わせられます

このサイトのプレイヤーには数秒単位で送り戻しするボタンがなく、シークバーをドラッグ
する以外に細かく位置を合わせる手段がありません。1 コマ送りと 1 秒送りがその間を
埋めます。コマ送りの幅は再生中に実測した映像のフレームレートに合わせるため、
30fps でも 60fps でも正しく 1 コマずつ進みます。

■ 保存先とファイル名

ダウンロードフォルダの中の singular-live フォルダに、
「番組名_再生位置.png」という名前で保存します。再生位置はミリ秒まで入るので、
続けて何枚撮ってもファイル名が重なりません。

ホットキーと保存先フォルダは設定画面から変更できます。

■ データを一切送信しません

外部のサーバーと通信しません。解析ツールも広告も入っていません。撮影した画像は
あなたのパソコンにだけ保存されます。

対象サイト以外では一切動作しません。ソースコードは MIT License で公開しています。
https://github.com/trapple/singular-live-screen-shot
```

## プライバシー関連の申告

審査で最も見られる箇所。**実装と食い違わないこと**が重要なので、
コードを変えたらここも必ず見直す。

### 単一用途の説明

```
SINGULAR LIVE (singular-live.thinkr.jp) のアーカイブ動画の再生ページで、再生中の
映像フレームを静止画ファイルとして利用者のパソコンに保存することが、この拡張機能の
唯一の目的です。静止画を狙った位置で取得できるようにするための、コマ単位・秒単位の
再生位置の移動もこの目的に含まれます。これ以外の機能は持ちません。
```

### 権限の正当化

**`downloads`**

```
撮影した静止画 (PNG) を利用者のダウンロードフォルダに保存するために使用します。
chrome.downloads.download を、拡張機能が生成した画像データに対してのみ呼び出します。
ダウンロード履歴の参照や、他のダウンロードの操作は行いません。
```

**`storage`**

```
利用者が設定画面で変更したホットキー、保存先サブフォルダ名、操作ボタンを表示するか
どうかの設定を保存するために使用します。保存するのはこれらの設定値のみで、
閲覧内容や個人を特定しうる情報は保存しません。
```

**ホスト権限 `https://singular-live.thinkr.jp/*`**

```
対象サイトの動画再生ページで、video 要素から映像フレームを取得し、一時停止中に
操作ボタンを表示するために必要です。コンテンツスクリプトはこのドメインにのみ
注入され、さらにその中でも動画の再生ページ以外では即座に処理を終了します。
他のサイトのページ内容にアクセスすることはありません。
```

### データ使用の申告

以下はすべて「収集しない」を選ぶ。

- 個人を特定できる情報: 収集しない
- 健康情報: 収集しない
- 金融情報・決済情報: 収集しない
- 認証情報: 収集しない
- 個人的な通信内容: 収集しない
- 位置情報: 収集しない
- ウェブの閲覧履歴: 収集しない
- ユーザーの操作履歴: 収集しない
- ウェブサイトのコンテンツ: 収集しない

3 つの証明にはすべてチェックを入れられる。

- 承認された用途以外でのデータの売却・譲渡をしていない
- 本拡張機能の単一用途と無関係な目的でのデータの使用・譲渡をしていない
- 信用度の判断や融資目的でのデータの使用・譲渡をしていない

## スクリーンショット

- サイズは **1280x800** または **640x400**。1 枚以上、5 枚まで
- 余白を入れず、指定サイズちょうどにする

> [!CAUTION]
> **限定公開や有料のコンテンツの映像が写り込まないようにすること。**
> ストアの掲載画像は、限定公開の拡張機能であっても URL を知る人は閲覧できる。
> 配信画面を撮るなら、冒頭の暗転やタイトル画面など、内容が分からない場面を選ぶ。
> 設定画面のスクリーンショットだけでも申請は通る。

撮る候補:

1. 設定画面 (ホットキーの一覧が分かる)
2. 一時停止中の操作ボタンが出ている画面
3. 保存されたファイルの一覧 (ファイル名の付き方が分かる)

## 審査で落ちうる点

この拡張機能は有料配信サービスの映像を静止画として保存する。ウェブストアのポリシーは
著作権侵害を助長するツールに厳しく、**拒否される可能性が現実にある**。

拒否された場合は理由が通知されるので、それを見てから次を判断する。パブリッシャー
あたりの公開枠 (2026-08-20 以降、新規アカウントは既定 2 枠) を消費するため、
枠に余裕がない場合は、通るかどうかを先に確かめる意味でも限定公開から試すのが安全。
