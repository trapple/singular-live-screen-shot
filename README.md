# Singular Live Screenshot

SINGULAR LIVE (https://singular-live.thinkr.jp) のアーカイブ動画から、再生 UI の
写り込みなしに 1920x1080 の PNG を保存する Chrome 拡張。

## できること

- 再生中でも一時停止中でも、ホットキーでその瞬間のフレームを PNG 保存
- 一時停止中に 1 フレーム単位のコマ送り / コマ戻し
- 一時停止中に 1 秒単位の送り / 戻し
- プレイヤーにコマ送り・撮影ボタンを追加
- フルスクリーン再生中も全機能が動作

## 使い方

| 操作 | キー | 備考 |
|---|---|---|
| 撮影 | `Shift+S` | 再生中でも一時停止中でも使える |
| 1 コマ送る / 戻す | `→` / `←` | 一時停止中のみ |
| 1 秒送る / 戻す | `Shift+→` / `Shift+←` | 一時停止中のみ |

一時停止すると、コントロールバーの上にボタンが表示される。

保存先は `<ダウンロードフォルダ>/singular-live/<番組名>_<再生位置>.png`。再生位置は
`HH-MM-SS.mmm` 形式なので、連写してもファイル名が衝突せず、ファイル名順に並べると
時系列順になる。

ホットキーと保存先は、拡張機能ページ (`⋮` →「拡張機能」→「拡張機能を管理」) で
この拡張の「詳細」を開き、「拡張機能のオプション」から変更できる。

### 仕組み

`<video>` のデコード済みフレームを canvas 経由で取り出しているため、画面に重なって
いる再生 UI は原理的に写り込まない。また、プレイヤーの表示サイズではなく配信の
ソース解像度 (1920x1080) で保存される。

コマ送りの粒度は `requestVideoFrameCallback` で実測した fps に基づく。30fps 配信でも
60fps 配信でも自動で追従する。

このサイトのプレイヤー (Uliza Player) は 10 秒送り / 戻しのボタンが無効化されており、
シークバーをドラッグする以外に細かく位置を合わせる手段がない。コマ送りと 1 秒送りは
その穴を埋める。

## インストール

Chrome ウェブストアには登録していないため、ZIP をダウンロードして手動で読み込む。

### 1. ダウンロード

[Releases](https://github.com/trapple/singular-live-screen-shot/releases) から最新の
`singular-live-screenshot-x.y.z.zip` をダウンロードする。

### 2. 解凍して、置き場所を決める

> [!IMPORTANT]
> **解凍したフォルダは、消したり移動したりしないこと。**
> Chrome は拡張の中身をコピーせず、このフォルダを参照し続ける。消すと拡張も動かなくなる。

ダウンロードフォルダは整理のときに消しやすいので、`書類` (Windows なら `ドキュメント`)
など普段触らない場所に置いておくとよい。

### 3. Chrome に読み込む

1. Chrome の拡張機能ページを開く
   - 右上の `⋮` →「拡張機能」→「拡張機能を管理」
   - または、アドレスバーに `chrome://extensions` と入力する
2. 右上の「デベロッパー モード」を ON にする
3. 左上に出る「パッケージ化されていない拡張機能を読み込む」を押す
4. 解凍したフォルダ (`manifest.json` が直接入っているフォルダ) を選ぶ

SINGULAR LIVE の再生ページを開けば使える。

### 更新するには

**自動更新はされない。** 新しいバージョンが出たら:

1. 新しい ZIP をダウンロードして解凍する
2. 手順 2 で決めた場所のフォルダを、新しいものに置き換える
3. 拡張機能ページ (`⋮` →「拡張機能」→「拡張機能を管理」) を開き、
   この拡張の再読み込みボタン (⟳) を押す

### 困ったときは

**Chrome を起動するたびに「デベロッパー モードの拡張機能を無効にする」と警告が出る**

ウェブストア以外から入れた拡張に対する Chrome の仕様。閉じれば拡張はそのまま動く。

**拡張が急に消えた / 動かなくなった**

解凍したフォルダを消したか移動した可能性が高い。手順 1 からやり直す。

**再生ページで何も起こらない**

対応しているのは `/play/<ID>/<ID>` 形式の再生ページだけ。トップページや番組一覧では
動作しない (意図した仕様)。

## 対応サイト

`https://singular-live.thinkr.jp/*` のみ。他のサイトでは一切動作しない。

さらに、その中でも再生ページ以外では何もしない。トップページや番組一覧ではキー入力の
監視すら行わない。

## 開発

ビルドは不要。

```bash
git clone git@github.com:trapple/singular-live-screen-shot.git
```

クローンしたディレクトリをそのまま「パッケージ化されていない拡張機能を読み込む」で
選べば動く。コードを変更したら拡張機能ページで再読み込みし、SINGULAR LIVE のページも
リロードする。

### リリース

`manifest.json` の `version` を上げてからタグを push すると、GitHub Actions が
配布用 ZIP を作って Release に添付する。

```bash
git tag -a v0.2.0 -m "..."
git push origin v0.2.0
```

タグと `manifest.json` の `version` が食い違っているとワークフローが失敗する
(ユーザーの手元の拡張のバージョン表示と Release がずれると、更新すべきか判断できなく
なるため)。

ZIP をローカルで作るだけなら:

```bash
./scripts/build-zip.sh
```

### テスト

```bash
node --test
```

DOM 操作・キー入力・ダウンロードは自動テストの費用対効果が低いため、純粋関数だけを
`node:test` で検証し、残りは手動確認で担保している。

### 構成

| パス | 責務 |
|---|---|
| `src/content/player.js` | サイト固有の DOM セレクタとタイトル整形。**構造が変わったらここだけ直す** |
| `src/content/capture.js` | canvas 撮影 → data URL |
| `src/content/stepper.js` | fps 実測、コマ送り、1 秒送り |
| `src/content/ui.js` | ボタンバーとトースト |
| `src/content/index.js` | キー待受と配線 |
| `src/background/index.js` | `chrome.downloads` での保存 |
| `src/shared/format.js` | タイムコード・ファイル名・fps・ホットキーの純粋関数 |

設計判断の記録は `docs/adr/` にある。

### 実装上の注意

- **ボタンバーはプレイヤールート (`.ulizahtml5`) の直下に置き、`z-index: 1000` を
  与えている。** Uliza のオーバーレイ (`.uliza-overlay-button-area` など) が
  `z-index: 5` でプレイヤー全面を覆っているため、その下に置くとクリックが吸われる。
  コントロールバー (`.vjs-control-bar`) の中に入れないのは、video.js の flex
  レイアウト (`order` 指定) に巻き込まれて既存ボタンの並びが崩れるため
- **ポインタ系イベントは `document` の capture フェーズで握り潰している。**
  動画領域のクリックは再生/一時停止に使われ、しかも `pointerdown` 段階で処理される
  ことがあるため、`click` だけを止めても間に合わない
- **プレイヤー要素の id は動的** (`UlizaPlayer-upc-content-<日時>-<ハッシュ>`) なので、
  セレクタは必ずクラスで書く
- content script は **isolated world** で動くため、DevTools の Console から `SLS` を
  直接叩くと `ReferenceError` になる。Console 上部の実行コンテキストを
  `Singular Live Screenshot` に切り替える必要がある
